\# Sample Logs



This folder contains selected `.evtx` sample files used for testing \*\*WinLog Sentinel\*\*.



\## Purpose



The files in this folder help validate:

\- EVTX parsing

\- Windows event detection

\- Sysmon event detection

\- dashboard output

\- CSV report export



\## Source



Some of these sample logs were taken from public Windows event log research datasets such as \*\*EVTX-ATTACK-SAMPLES\*\* and other community security testing sources.



\## Notes



\- Only a limited number of files are included here for testing.

\- The original datasets may contain many more files and categories.

\- Some filenames may reference attack techniques because they are designed for detection engineering and blue-team testing.



\## Usage



Upload any file from this folder into the WinLog Sentinel app to test detections.



\## Disclaimer



These files are shared strictly for educational and defensive security purposes.
